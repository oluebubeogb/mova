# Mova Site Kits

External catalog for the Quick Setup Wizard.

Bundled with the Quick Setup plugin (canonical location). To add custom kits without touching the plugin, you may also place them in a `mova-kits/` folder in the Mova root — it is checked first.

Tokens: `{{site_name}}`, `{{tagline}}`, `{{about}}`, `{{contact}}`, `{{year}}`.
Colors via CSS variables from DesignConfig.
